# Josh Pomer — Surf Photography & Frame Grabs

A responsive, dark cinematic portfolio homepage for surf photography, collectible frame grabs, and films.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, set the source to **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait a few minutes for GitHub Pages to publish the site.

Expected site address: https://postmodernsurfer-jpg.github.io/josh-pomer-website/

## Before launch

- Replace the Unsplash demo imagery with your own photographs.
- Replace the placeholder contact email `prints@joshpomer.com` with the address you want to use.
- Add actual print details, pricing, shipping, and payment options.

The site is plain HTML and CSS, so it does not require a build step.
